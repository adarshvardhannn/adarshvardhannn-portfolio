# Adarsh Vardhan | Developer & Cybersecurity Portfolio

A personal portfolio showcasing my journey in **Cybersecurity**, **Digital Forensics**, **Android Security**, and **Full-Stack Development**.

Built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

---

## Overview

This portfolio is a central space to explore my technical skills, projects, experience, and achievements as a Cybersecurity student at **National Forensic Sciences University (NFSU), Bhopal**.

It features a modern cyber-inspired interface with interactive elements, project showcases, and an integrated contact system.

---

## Features

- **Modern UI:** Dark cyber-tactical theme with glassmorphism and smooth animations.
- **AdarshOS Terminal:** Interactive terminal simulation with custom commands and project information.
- **Project Showcase:** Dedicated sections highlighting cybersecurity and development projects.
- **Responsive Design:** Optimized for desktops, tablets, and mobile devices.
- **Contact System:** Serverless contact form with input validation and spam protection.
- **Smooth Animations:** Framer Motion, GSAP, and Lenis integration.

## Interactive AdarshOS Terminal

Explore my portfolio through a simulated command-line interface.

Available commands include:
- `ls` – List available directories and files.
- `cd` – Navigate between directories.
- `cat` – Read project and profile information.
- `whoareyou` – Learn about me.
- `hello` – Display a terminal greeting.
- `clear` – Clear the terminal.
- `exit` – Return to the main portfolio.

## Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/adarshvardhannn/adarshvardhannn-portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd adarshvardhannn-portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
```
The production-ready files will be generated inside the `dist/` directory.

---

## Deployment

The portfolio is configured for deployment on **Vercel**.

1. Import the GitHub repository into Vercel.
2. Configure the required environment variables.
3. Deploy the project.
4. Connect your custom domain.

### Environment Variables

Configure the following variables in your deployment platform:

```env
WEB3FORMS_ACCESS_KEY=your_access_key
CONTACT_RECEIVER_EMAIL=your_email@example.com
```

> **Note:** Keep all private credentials in server-side environment variables. Never commit actual API keys or `.env` files to GitHub.
